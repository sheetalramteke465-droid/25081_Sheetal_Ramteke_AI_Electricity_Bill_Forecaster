I’m happy to share my Python mini project: **AI Electricity Bill Forecaster** ⚡

This console-based project estimates next month’s electricity bill using a simple linear-regression calculation based on the previous six monthly bills. It also estimates appliance electricity costs and potential savings from reducing daily AC usage.

**What I practiced:**
- Python loops, lists, dictionaries, functions, and user input
- A basic least-squares linear-regression calculation
- Electricity cost estimation and documenting project limitations

This is an educational prototype. Predictions and savings are estimates; actual bills may vary because of tariffs, taxes, fixed charges, and changes in usage.
